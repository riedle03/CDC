# CDC — Counseling Data Converter

> 반복되는 상담 업로드 작업을 정리된 입력 흐름으로 바꾸고, 검토 가능한 결과표까지 한 화면에서 완성합니다.

**라이브 데모:** https://riedle03.github.io/CDC/

---

## 개요

학교 상담사가 매번 수동으로 입력하던 상담 데이터 업로드 작업을 자동화합니다.
원시 텍스트(날짜, 학번, 이름)를 붙여넣으면 16컬럼 엑셀 업로드 파일을 즉시 생성합니다.

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| **기본값 설정 저장** | 상담분류·학년·소속 등 13개 항목을 localStorage에 프리셋 저장 |
| **원시 텍스트 파싱** | 날짜 8가지 형식, 시간 포함/제외 자동 인식 |
| **인라인 편집** | 생성된 테이블에서 셀 직접 수정 가능 |
| **실시간 검증** | Zod 스키마 기반 이슈 하이라이트 |
| **엑셀 내보내기** | 검증 통과 후 .xlsx 다운로드 |

---

## 4단계 워크플로우

```
Step 1  기본값 설정    →  상담분류, 학년, 소속 등 고정값 설정
Step 2  원시 데이터    →  텍스트 붙여넣기 후 데이터 생성
Step 3  결과 검토      →  생성된 행 수정 및 이슈 확인
Step 4  엑셀 내보내기  →  검증 통과 후 .xlsx 다운로드
```

---

## 입력 형식 예시

```
2026-03-09 12:30 2401 김하늘
26.03.02 2402 이서준
26-03-02 2403 박민서
```

지원하는 날짜 형식: `YYYY-MM-DD`, `YY.MM.DD`, `YY-MM-DD`, `YYYYMMDD` 등 8가지

## 기술 스택

| 분류 | 기술 |
|------|------|
| 프레임워크 | React 19 + TypeScript |
| 빌드 도구 | Vite 6 |
| 상태 관리 | Zustand 5 |
| 데이터 검증 | Zod 3 |
| 엑셀 생성 | SheetJS (xlsx) |
| 폰트 | Pretendard Variable |
| 배포 | GitHub Pages (gh-pages) |
